## 🏎️ Overview

A modern, high-performance, supercar-themed website for **OnlySuds Mobile Detailing**, an owner-operated doorstep automotive detailing business in Austin, Texas.

Built with **React 18, TypeScript, Tailwind CSS, and Vite**, ready for instant zero-config continuous deployment on **Netlify** or **Vercel**.

---

## ✨ Features

- **Red & Black Supercar Aesthetic:** High-contrast carbon fiber palette (`#0B0C0E`), race red accents (`#E50914`), speed gauge motifs, and neon edge glow.
- **Real Social Media Assets:** Integrated genuine driveway transformation photography sourced directly from OnlySuds' Facebook presence.
- **Interactive Before & After Slider:** Touch- and mouse-enabled dual-layer comparison showing road grime vs showroom mirror gloss finish.
- **Dynamic Quote Generator:** Interactive vehicle class selector (Coupe, Sedan, Mid SUV, Full Truck) with treatment add-ons that generate pre-filled WhatsApp quote requests.
- **Audio Micro-Interactions:** Synthesized Web Audio API sound effects (foam cannon spray and tactile cockpit clicks) with header mute toggle.
- **100% Mobile Optimized:** Sticky mobile cockpit conversion bar with 1-tap call and quote buttons.

## 🌐 Deploy to Netlify / Vercel

### Vercel
1. Import this repository in your Vercel Dashboard.
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**.

### Netlify
1. Connect this repository in Netlify.
2. Build Command: `npm run build`
3. Publish Directory: `dist`
4. Pre-configured via `netlify.toml`. Click **Deploy site**.
